# EXP-CZ-002 preregistration

Status: REPORTED. The experiment was frozen before its sealed evaluation. Its scored sealed set and verification material are released in [the reveal folder](../../public-commitments/reveal/EXP-CZ-002/).

## What was fixed before the sealed run

The approved design fixed the founder pool, arms, budgets, task count, scoring rule, primary endpoint, secondary endpoints, and stop rules before sealed generation. It used a fresh scored set and a hash-bound manifest. The public commitment chain is recorded in [EXP-CZ-002 commitments](../../public-commitments/EXP-CZ-002.md).

The hypotheses are the approved `DRAFT_SPEC.md` section 8 hypotheses: H2.1 is the primary comparison of T3 coverage with the pooled tool reference at the 4x budget. H2.2 tests the outline gate by regime. H2.3 tests novel solves against P. H2.4 tests collaboration beyond tools. H2.5 reports the tool effect separately. This page does not disclose task content, a salt, or a sealed-file location.

The public records include PREGEN, PRERUN, POSTRUN, BEACON, and amendments A1 through A6. Given the reveal folder and release archive, the verifier checks the fixed scored-set file and salt commitment, the PREGEN and PRERUN records, the hardcoded hashes of all ten public commitment files, the POSTRUN digest list against all 44 released result and ledger files, and the scorer-envelope bindings to PRERUN, POSTRUN, BEACON, A5, and A6.

## Scope

The experiment tests this frozen founders-pool setup on this sealed instrument. It is not a claim about other task distributions, larger members, storage, or general intelligence.
